# Segurança

Esta é uma versão de estudo do Piano Livre, ainda em fase beta.

**Não publique credenciais, chaves, dados pessoais, backups, arquivos musicais privados ou informações sensíveis em issues.**

Para reportar vulnerabilidades, prefira os **avisos privados de segurança do GitHub** se estiverem habilitados. Caso não estejam, solicite ao mantenedor um canal privado sem divulgar detalhes exploráveis publicamente.

A importação MusicXML/MXL, a integração WebView–Java e os arquivos ZIP de partituras exigem revisões e testes contínuos. Não assuma que conteúdo externo seja confiável.

Os APKs gerados automaticamente pelo CI utilizam **assinatura de depuração temporária** e um identificador de aplicação separado, e não servem como atualização direta das betas privadas.
