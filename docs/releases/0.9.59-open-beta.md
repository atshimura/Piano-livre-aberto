# Candidata Piano Livre 0.9.59-open-beta (código 68)

**Estado:** candidata em PR #91, sem Release pública autorizada. Este arquivo não é anúncio de publicação. A Release mais recente verificada antes desta entrega foi a 0.9.58-open-beta.

## Implementação E — tela Descobrir

- Pauta Sol/Fá padrão ampliada em ~27% nos viewports de referência, sem alterar barra superior ou painel direito.
- Notas isoladas, acordes e sequências iniciam na mesma coluna após as claves, com acidentes, ledgers e rolagem preservados.
- Ajuste automático reversível da pauta para extremos do piano (Lá0/MIDI21 e Dó8/MIDI108 simultâneos); última entrada retida permanece legível após Note Off; nova entrada comum restaura automaticamente a pauta maior. Faixa técnica MIDI0+127 também suportada.

## Pacote, compatibilidade e publicação

Pacote `br.org.pianolivre.opensource`, incremento 67→68 sem alterar formatos de dados ou permissões. Assinatura permanente na build de `main` somente com Actions Secrets; o PR usa APK debug descartável. O aplicativo continua offline. A publicação é bloqueada por `pianolivre.beta.publishApproved=false` e requer autorização específica para a versão 0.9.59, além de gates build/emulator no SHA exato.

**Ensaios:** testes JVM, Chromium/OSMD, capturas Android e compatibilidade com versões anteriores somente considerados concluídos conforme os resultados reais no [PR #91](https://github.com/atshimura/Piano-livre-aberto/pull/91) e [documento 100](../100-IMPLEMENTACAO-E-E-D-VALIDACAO-ENTREGA.md). Validação física com Realme 7 5G, Lenovo Tab M9 e Yamaha P-45 continua pendente.
