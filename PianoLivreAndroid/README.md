# Piano Livre Android

Código Java/Android, interface MIDI e visualização MusicXML.

O pacote público `br.org.pianolivre.opensource` é uma distribuição experimental separada da beta privada, para não substituir instalações existentes assinadas com outro certificado.

Leia o [README do projeto](../README.md), a [licença](../LICENSE) e os [termos de contribuição](../CONTRIBUTING.md).
